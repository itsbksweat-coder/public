# Color Dice Predictor

Mobile-friendly color dice trend tracker for the 4-dice color roller.

## Live site

Development preview:

https://raw.githack.com/itsbksweat-coder/public/main/index.html

## Features

- Tap the four colors shown on stream
- Saves completed rounds in your browser
- Undo and clear controls
- Recent round history
- Recency-weighted color trend ranking
- Mobile layout for iPhone/Safari

The trend panel summarizes the results you enter; random dice outcomes are not guaranteed or reliably predictable from prior rolls.
